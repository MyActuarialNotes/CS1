## 1. Structure

```

## 3. Mandatory Template

```

```

```

## 6. Links (Strict Rule)

Only Five types allowed:
* Prerequisite link
* Next concept link
* Checklist link
* Define link
* Example link
No random linking.
Random linking feels smart but creates fog.
A sword is sharp because it has one edge.


## 7. Dashboard (Single Control Room)

Master Dashboard
Shows:
All Draft
All Review
Dependency gaps
Missing checklist
Words without examples
Broken chains
If something is not visible here, it does not exist.


## 8️⃣ Weekly Ritual (The Secret Layer)
Every week:
Convert 10 drafts → review
Upgrade 5 review → exam-safe
Refactor 2 old notes
Check dependency graph
Systems die without ritual.
Discipline is the invisible plugin

```mcq
id: rv-001
q: What is an event?
choices:
  A: A single outcome
  B: A set of outcomes
  C: The sample space itself
  D: A probability value
answer: B
explain:
  A: An outcome is one result, not a set.
  B: Correct — an event is a subset of the sample space.
  C: The sample space is the set of *all* outcomes.
  D: Probabilities measure events; they are not events.
```
